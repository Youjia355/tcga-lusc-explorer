# tcga-lusc-explorer
An interactive dashboard for exploring gene mutation frequencies and RNA expression by pathologic stage in TCGA lung squamous cell carcinoma (TCGA-LUSC). Built for the BMI 706 data visualization course.

Open index.html in a browser. The page runs offline and embeds aggregate counts only. Select a pathologic stage, click a gene in the mutation ranking, and inspect the expression histogram.

## Scope and join audit

TCGA-LUSC PanCancer Atlas 2018, via cBioPortal. The dashboard ranks eight selected genes. Expression uses log2(RSEM + 1). The GDC STAR Counts workflow described in the original process book uses a different expression source.

Stage comes from the patient clinical record. Clinical sample metadata joins patient IDs to primary tumor sample IDs. There is one primary sample per retained patient in this export. Mutation calls join by sample ID and count each profiled patient once per gene. The denominator comes from the mutation-profiled sample list. Expression joins using the matrix sample columns, with separate counts per gene. Each view uses the cases available for its assay. Missing stage is its own group. Stage substages are grouped into I–IV.

See join_audit.json for counts by stage. The all-stage cohort has 487 linked primary samples, 484 mutation-profiled, 484 RNA-profiled, and 481 with both assay profiles. Stage IV has seven patients.

Rebuild with Python 3 and curl by running `python3 prepare.py`. Source downloads are cached in .cache and excluded from Git. The generated page contains stage-level counts and histograms. The builder fetches the current study snapshot when the cache is empty.

Study source: https://www.cbioportal.org/study/summary?id=lusc_tcga_pan_can_atlas_2018
DataHub: https://github.com/cBioPortal/datahub/tree/master/public/lusc_tcga_pan_can_atlas_2018
The data were generated by the TCGA Research Network.

## GitHub handoff

Copy the package files into your team's repository and commit them. Under Settings → Pages, choose Deploy from a branch and select the branch and root directory containing index.html. Open the resulting URL in a signed-out browser and replay the interaction. When the tested version is ready, create a GitHub release tagged v0.1 from the same deployed commit and add the live and repository links to the process book.

This first slice covers the stage filter, mutation ranking, and expression view. Add and validate survival for the later prototype milestone if your study includes it.
