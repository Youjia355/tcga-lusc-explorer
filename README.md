# TCGA-LUSC Explorer

An interactive dashboard for exploring gene mutation frequencies and RNA expression by pathologic stage in TCGA lung squamous cell carcinoma (TCGA-LUSC). Built for the BMI 706 data visualization course.

## Run the Explorer

From the repository root on macOS:

```sh
open docs/index.html
```

You can also double click `docs/index.html` in Finder. The generated page contains the data it needs, so no installation, server, or data download is needed to use it. Set pathologic stage, sex, and age filters independently for Cohorts A and B. Use the shared gene selector or click a mutation bar to update both expression box plots. Switch the expression grouping between clinical stage and mutation status. The survival curves, stage distribution, availability counts, and cohort-level expression heatmap follow the cohort filters.

The dashboard has three tabs:

- **Cohort comparison** — the side-by-side Cohort A and B view described above.
- **Mutation matrix** — one column per mutation-profiled patient, colored by mutation type (truncating, splice, missense, in-frame), with stage, sex, age and vital status tracks above. Show all patients or either cohort, sort by mutation pattern, stage or survival time, and hover a column for that patient's mutations. Click a gene name to make it the shared gene, or click a column to open that patient in the table.
- **Patient table** — one row per patient with clinical fields, survival, mutations in the eight selected genes and expression of the shared gene. Sort by any column, search by patient ID, gene or protein change (for example `tp53 r273`), and download the shown rows as CSV.

## Repository structure

- `docs/index.html` — Browser entry point and generated dashboard. GitHub Pages publishes the `docs/` directory.
- `src/dashboard.template.html` — Editable layout and CSS.
- `src/dashboard.js` — Linked chart rendering and interaction logic.
- `scripts/prepare.py` — Main build script. Downloads source files, joins clinical records with mutation and expression data, and generates the dashboard and join audit.
- `data/join_audit.json` — Summary of linked cases and assay coverage by stage.

## Rebuild after editing

From the repository root, run the following with Python 3 and curl installed:

```sh
python3 scripts/prepare.py
open docs/index.html
```

On Windows, use `python scripts\prepare.py` and `start docs\index.html`.

Downloads are cached in `.cache/`, which Git ignores. The generated page includes per-patient open-access clinical fields, mutations and expression for the selected genes, aggregate mutation counts, expression summaries, and Kaplan–Meier plot coordinates. To refresh the upstream files, remove the local cache before running the script again.

## Data scope

The prototype uses the cBioPortal TCGA-LUSC PanCancer Atlas 2018 export and ranks eight selected genes. Expression is displayed as log₂(RSEM + 1). Clinical stage comes from patient records and is linked to primary tumor samples. Mutation rates use mutation-profiled patients as the denominator, with each patient counted once per gene.

The verified snapshot contains 487 patients with a primary sample, 484 with mutation profiles, 484 with RNA profiles, and 481 with both. Stage IV includes seven patients, and 481 records have usable overall survival time and event status. See `data/join_audit.json` for stage-level counts.

- [cBioPortal study](https://www.cbioportal.org/study/summary?id=lusc_tcga_pan_can_atlas_2018)
- [cBioPortal DataHub source files](https://github.com/cBioPortal/datahub/tree/master/public/lusc_tcga_pan_can_atlas_2018)

The data were generated by the TCGA Research Network.

## Process book sketches

The two-column design follows the sketch with Cohorts A and B side by side. The linked expression plot can group by detected mutation status, as shown in the mutation matrix sketch. The overview shows the total primary-tumor cohort, age at diagnosis and recorded ethnicity. Choose a target cohort in the stage panel and click a stage to filter it. Expand the assay panel for counts and percentages, or treatment history for recorded radiation therapy. The cohort breakdown table shows aggregate counts for the active comparison. Heatmap columns are cohort means. The mutation matrix and patient table tabs follow the mutation matrix and patient table sketches. The PanCancer Atlas clinical export has no smoking history, so the sketch's smoking track is not shown. Drug-specific medication and geographic comparisons are outside this build.
